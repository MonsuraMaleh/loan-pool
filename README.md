LoanPool – Decentralized Lending & Liquidity Pooling
LoanPool allows users to supply liquidity to earn interest while enabling borrowers to access funds using collateral protection.

Core Capabilities
- Liquidity supply and withdrawal for lenders
- Borrowing with over-collateralization requirements
- Accrued interest distributed to liquidity providers
- Transparent debt and collateral visibility

Key Functions
deposit, withdraw, borrow, repay, get-liquidity, get-debt, get-collateral
